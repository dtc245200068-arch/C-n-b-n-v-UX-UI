
# Bài 01 - Thực hành sử dụng Adobe Color

## 1. Mục tiêu
Tìm hiểu công cụ Adobe Color và áp dụng nguyên tắc
phối màu trong thiết kế giao diện UX/UI.

## 2. Công cụ sử dụng
- Adobe Color: https://color.adobe.com/
- Visual Studio Code
- GitHub

## 3. Quy tắc phối màu
Analogous - Phối màu tương đồng.

## 4. Bộ màu tham khảo

| STT | Tên màu | Mã HEX |
|-----|---------|--------|
| 1 | Deep Blue | #0B3C5D |
| 2 | Ocean Blue | #176B87 |
| 3 | Turquoise | #64CCC5 |
| 4 | Mint | #A5F1E9 |
| 5 | Light Mint | #E8F8F5 |

## 5. Ứng dụng
- Màu xanh đậm: Header và tiêu đề
- Màu xanh dương: Nút bấm và liên kết
- Màu xanh ngọc: Điểm nhấn
- Màu mint: Thành phần phụ
- Màu sáng: Nền trang web

## 7. Kết luận
Qua bài thực hành, em đã tìm hiểu cách sử dụng
Adobe Color để lựa chọn và phối hợp màu sắc
phù hợp khi thiết kế giao diện website.
