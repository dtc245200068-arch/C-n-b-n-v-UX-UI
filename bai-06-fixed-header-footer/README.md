# Bài 06 – Fixed Header và Fixed Footer

Bài thực hành CodeGym sử dụng HTML và CSS để tạo thanh điều hướng cố định ở đầu trang và footer cố định cuối màn hình.

## Cách chạy
Mở `index.html` bằng trình duyệt hoặc Live Server trong VS Code, sau đó cuộn trang để kiểm tra header và footer.

## Kỹ thuật
- `position: fixed`, `top: 0` cho header.
- `position: fixed`, `bottom: 0` cho footer.
- `z-index` giữ thanh điều hướng nổi trên nội dung.
- `padding` tránh che nội dung.
- Media query giúp hiển thị trên điện thoại.
