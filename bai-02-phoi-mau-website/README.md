
# BÀI 02 - THỰC HÀNH SỬ DỤNG MÀU SẮC TRONG TRANG WEB

## 1. Mục tiêu
Thực hành phối màu đơn sắc (Monochromatic)
trong thiết kế giao diện website.

## 2. Phiên bản xanh dương
Sử dụng màu chính #00ADEE.

Bảng màu:
- #00ADEE
- #00B2EF
- #00BFF2
- #8DD7F7
- #C6E9FA

## 3. Phiên bản xanh lá
Sử dụng màu chính #087F5B.

Bảng màu:
- #087F5B
- #099268
- #12B886
- #96F2D7
- #E6FCF5

## 4. Nội dung thực hiện
- Phối màu đơn sắc cho website.
- Đổi màu nền chính.
- Đổi màu nhãn ON SALE/PREVIEW.
- Đổi màu nền nội dung.
- Đổi màu footer.
- Giữ màu chữ đen.
- Tạo hai phiên bản giao diện.

## 5. Cách chạy
Mở index.html trong mỗi thư mục bằng trình duyệt
hoặc sử dụng Live Server trên VS Code.

## 6. Kết luận
Qua bài thực hành, em đã biết cách sử dụng
các sắc độ của một màu chủ đạo để xây dựng
giao diện website hài hòa và nhất quán.
